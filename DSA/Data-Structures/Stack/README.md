# Stack

## Overview

A **stack** is a linear data structure that follows the **LIFO** (Last In, First Out) principle. Elements are added and removed from the same end (the top).

## Complexity

| Operation | Time Complexity |
|-----------|----------------|
| Push      | O(1)           |
| Pop       | O(1)           |
| Peek/Top  | O(1)           |
| Search    | O(n)           |
| Space     | O(n)           |

## Key Techniques

- **Monotonic Stack** – maintain increasing or decreasing order to solve next-greater-element problems
- **Expression Evaluation** – parsing and evaluating arithmetic expressions
- **Backtracking / DFS** – use a stack to simulate recursion iteratively
