# Data Structures

A data structure is a way of organizing and storing data so that it can be accessed and modified efficiently.

## Topics

| Folder | Description |
|--------|-------------|
| [Arrays](./Arrays/) | Contiguous block of memory storing elements of the same type |
| [Linked-List](./Linked-List/) | Linear collection of nodes, each pointing to the next |
| [Stack](./Stack/) | LIFO (Last In, First Out) data structure |
| [Queue](./Queue/) | FIFO (First In, First Out) data structure |
| [Trees](./Trees/) | Hierarchical structure with a root and subtrees of children |
| [Graphs](./Graphs/) | Collection of nodes (vertices) connected by edges |
| [Hash-Table](./Hash-Table/) | Key-value store with O(1) average-case lookup |
| [Heap](./Heap/) | Complete binary tree satisfying the heap property |
| [Trie](./Trie/) | Tree for storing strings, useful for prefix-based search |
