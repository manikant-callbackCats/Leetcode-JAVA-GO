# Algorithms

An algorithm is a step-by-step procedure for solving a problem or accomplishing a task.

## Topics

| Folder | Description |

| [Dynamic-Programming](./Dynamic-Programming/) | Solving problems by breaking them into overlapping subproblems |
| [Greedy](./Greedy/) | Making locally optimal choices at each step |
| [Backtracking](./Backtracking/) | Building solutions incrementally and abandoning invalid paths |
| [Divide-and-Conquer](./Divide-and-Conquer/) | Splitting problems into independent subproblems |
| [Two-Pointers](./Two-Pointers/) | Using two indices to reduce time complexity |
| [Sliding-Window](./Sliding-Window/) | Maintaining a window of elements over a sequence |
| [Graph-Algorithms](./Graph-Algorithms/) | BFS, DFS, Dijkstra, Bellman-Ford, and more |
| [Bit-Manipulation](./Bit-Manipulation/) | Solving problems using bitwise operations |
