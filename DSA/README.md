# DSA - Data Structures and Algorithms

This directory contains solutions, notes, and implementations organized by topic in **Java** and **Go**.

## Structure

```
DSA/
├── Data-Structures/
│   ├── Arrays/
│   ├── Linked-List/
│   ├── Stack/
│   ├── Queue/
│   ├── Trees/
│   ├── Graphs/
│   ├── Hash-Table/
│   ├── Heap/
│   └── Trie/
└── Algorithms/
    ├── Sorting/
    ├── Searching/
    ├── Dynamic-Programming/
    ├── Greedy/
    ├── Backtracking/

    ├── Two-Pointers/

```

## How to Use

- Each subfolder contains a `README.md` explaining the concept, complexity analysis, and related LeetCode problems.
- Solutions are provided in **Java** (`.java`) and **Go** (`.go`).

## Complexity Cheat Sheet

| Operation | Array | Linked List | Stack | Queue | Hash Table | BST (avg) | Heap     |
|-----------|-------|-------------|-------|-------|------------|-----------|----------|
| Access    | O(1)  | O(n)        | O(n)  | O(n)  | O(1)       | O(log n)  | O(n)     |
| Search    | O(n)  | O(n)        | O(n)  | O(n)  | O(1)       | O(log n)  | O(n)     |
| Insert    | O(n)  | O(1)        | O(1)  | O(1)  | O(1)       | O(log n)  | O(log n) |
| Delete    | O(n)  | O(1)        | O(1)  | O(1)  | O(1)       | O(log n)  | O(log n) |
