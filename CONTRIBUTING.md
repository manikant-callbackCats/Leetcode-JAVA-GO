## 🌟 Ways to Contribute

There are many ways to get involved — pick what suits you best!

| 🧩 Contribution Type | Description |
|----------------------|-------------|
| ➕ **Add a Solution** | Solve a new LeetCode problem in Java and/or Go |
| 🐛 **Fix a Bug** | Spot an incorrect solution? Fix it! |
| ♻️ **Optimize** | Submit a more efficient or cleaner solution |
| 📝 **Improve Docs** | Enhance README, comments, or explanations |
| 🌐 **Add Another Language** | Solutions in Python, C++, etc. are welcome too |

## 🛠️ Setting Up

```bash
# 1. Fork the repository on GitHub

# 2. Clone your fork
git clone https://github.com/<your-username>/Leetcode-JAVA-GO.git
cd Leetcode-JAVA-GO

# 3. Create a feature branch
git checkout -b add/123-two-sum

# 4. Make your changes

# 5. Push and open a Pull Request
git push origin add/123-two-sum
```

## 📁 File & Folder Structure

Please follow this folder layout when adding new solutions:

```
Leetcode-JAVA-GO/
├── Java/
│   └── <ProblemNumber>-<ProblemName>/
│       └── Solution.java
└── Go/
    └── <ProblemNumber>-<ProblemName>/
        └── solution.go
```

**Example:**

```
Java/1-TwoSum/Solution.java
Go/1-TwoSum/solution.go
```

## ✅ Checklist Before Submitting

Before opening a PR, make sure you've checked all the boxes:

- [ ] 🗂️ Files are placed in the correct folder with the right naming
- [ ] 💬 Problem link, difficulty, and complexity are included as comments
- [ ] ✅ Solution compiles and runs correctly
- [ ] 🧪 Edge cases are handled
- [ ] 🧹 Code is clean, readable, and well-named
- [ ] 📝 Branch name is descriptive (e.g., `add/123-two-sum`)

---

## 🔄 Pull Request Process

1. **Fork** the repo and create a dedicated branch
2. **Write** your solution following the templates above
3. **Verify** your solution against the LeetCode test cases
4. **Open** a Pull Request with a clear title and description
5. **Respond** to any review feedback promptly
6. 🎉 Get merged and earn your contributor badge!

> ⚡ **Tip:** Keep PRs small and focused — one problem per PR is ideal!

We're a welcoming, inclusive community. By contributing, you agree to:
